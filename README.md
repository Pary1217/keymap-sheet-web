# キーマップ チートシート(ブラウザ版)

VIA / Vial のキーボードを USB でつないで、今のキーマップを読み、レイヤーごとのチートシートを作るページです。
キーマップを変えることもできます。Chrome / Edge の WebHID を使います。

- 読んだキーマップは、ブラウザの中(localStorage)だけに保存します。どこにも送りません。
- JSON で保存・読み込みができます。PC 版のアプリ(別のリポジトリ)と同じ形です。
- PDF は、ブラウザの「印刷 → PDF に保存」で作ります(A4 横、余白なし)。
- キーマップを変えるときは、先に今のキーマップを「(変更前)」として保存し、1 キーずつ書いて読み直して確かめます。
  「変更前に戻す」で元に戻せます。書き込みモード(QK_BOOT)と設定を消すキー(QK_CLEAR_EEPROM)は置けません。
- Vial のキーボード(Cornix LP など)は、配列の形をキーボードから読みます。
  VIA / Remap のキーボードは、公式の配列の定義を GitHub から読みます。今は Keyball44 だけです。

## お使いになる前に(大事な注意)

- このページは個人が作った非公式のツールです。各キーボードのメーカー・販売店や、VIA・Vial・Remap の開発元が作ったり認めたりしたものではありません。製品名・ツール名は、使えるキーボードや仕組みを説明するために書いています。
- このページは USB ケーブルでつないだときだけ使えます(キーボードが無線で設定できる場合でも、このページは有線だけです)。
- 変えるのはキーの割り当てだけで、ファームウェアは書き換えません。変える前に、今のキーの割り当てを「(変更前)」として保存します。抜けたり接続が切れたりすると、一部のキーだけが変わった状態になることがあります。変えたあとは、実際にキーを押して確かめてください。
- 元に戻せるのは、このページが保存したキーの割り当てだけです。キーボードのほかの設定(コンボ、タップダンス、マクロ、ライトなど)や、ファームウェアの版が違うときの復元はできません。ファームウェアを更新すると、設定が初期化されたり、保存した設定を読み込めなくなったりする場合があります。
- 動き方や元に戻せること、メーカー保証への影響は約束できません。ここに書いたことを確かめたうえで、ご自身の判断でお使いください。

## 手元で動かす

```
python -m http.server 8000
```

で `http://localhost:8000/` を開きます(WebHID は https か localhost でしか動きません)。

## 確かめ方

`tests/compare.html` は、PC 版(Python)と同じ表示になるかを、全キーコードと Keyball44 の配列で比べます。
`tests/expected.json` は PC 版で作ります(リポジトリには入れていません)。
