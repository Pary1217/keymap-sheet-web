キーマップ チートシート

VIA / Vial のキーボードを USB でつないで、今のキーマップを読み、レイヤーごとのチートシートを作ります。 4 でキーマップを変えることもできます。読んだキーマップは、このブラウザの中だけに保存します(どこにも送りません)。

このブラウザではキーボードとやりとりできません。Chrome か Edge で開いてください (保存した JSON からチートシートを作ることはできます)。

お使いになる前に(大事な注意)
  • このページは個人が作った非公式のツールです。各キーボードのメーカー・販売店や、VIA・Vial・Remap の開発元が作ったり認めたりしたものではありません。製品名・ツール名は、使えるキーボードや仕組みを説明するために書いています。
  • このページは USB ケーブルでつないだときだけ使えます(キーボードが無線で設定できる場合でも、このページは有線だけです)。
  • 変えるのはキーの割り当てだけで、ファームウェアは書き換えません。変える前に、今のキーの割り当てを「(変更前)」として保存します。抜けたり接続が切れたりすると、一部のキーだけが変わった状態になることがあります。変えたあとは、実際にキーを押して確かめてください。
  • 元に戻せるのは、このページが保存したキーの割り当てだけです。キーボードのほかの設定(コンボ、タップダンス、マクロ、ライトなど)や、ファームウェアの版が違うときの復元はできません。ファームウェアを更新すると、設定が初期化されたり、保存した設定を読み込めなくなったりする場合があります。
  • 動き方や元に戻せること、メーカー保証への影響は約束できません。ここに書いたことを確かめたうえで、ご自身の判断でお使いください。

1. キーボードを読む

USB ケーブルでつないでください(このページは有線だけで使えます)。 Vial / VIA / Remap のサイトを開いていたら、先に閉じてください(同時には使えません)。

2. 保存したキーマップ

チートシートにするものに印を付けてください。PC 版のアプリで保存した JSON も読み込めます。

    3. チートシートを作る

    PDF にするには、印刷の画面で「送信先: PDF に保存」、用紙 A4・横、余白「なし」を選んでください。

    4. キーマップを変える

    キーボードを選ぶと、まず今のキーマップを読んで「(変更前)」として 2 に保存します。 キーを押して新しいキーを選ぶと、すぐキーボードに書き込みます(1 キーごとに読み直して確かめます)。 「変更前に戻す」で、いつでも元に戻せます。書き込みモードのキー(QK_BOOT)は置けないようにしています。
